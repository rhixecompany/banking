# Code Documentation Standards

This directory contains language-specific documentation standards and examples for the Banking project.

## Contents

- [TypeScript](./typescript.md) - TypeScript coding standards and examples
- [Python](./python.md) - Python coding standards and examples

## Quick Reference

| Language   | Standard Tool         | Documentation Format |
| ---------- | --------------------- | -------------------- |
| TypeScript | JSDoc / TSDoc         | `.ts`, `.tsx` files  |
| Python     | Sphinx / Google Style | `.py` files          |

## Guidelines

- Always document public APIs
- Include usage examples for complex functions
- Keep documentation near the code (inline or adjacent)
- Use consistent formatting within each language
